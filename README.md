Program Sistem Manajemen Tiket Bioskop digunakan untuk mengelola data tiket yang terdiri dari:

1. ID Tiket
2. Judul Film
3. Studio
4. Jam Tayang
5. Nomor Kursi
6. Harga Tiket

# Fitur utama
1. Menambah data tiket
2. Menampilkan data tiket
3. Mengubah data tiket
4. Menghapus data tiket
5. Mencari data tiket

# Error Handling 
1. Jika data yang di inputkan tidak sesuai dengan tipe data 
2. Jika ID data yang dicari tidak ada
3. Jika menu yang dimasukkan tidak berupa angka
4. Jika ID tiket yang ditambahkan sudah digunakan
5. Jika data yang dimasukkan tidak lengkap.
